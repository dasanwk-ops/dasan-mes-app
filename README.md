# 다산산업 MES 재발방지 수정 후보 — RC1

**2026-09-11 / 시험용입니다. 운영 main에 바로 올리지 마세요.**

이 파일 묶음은 사용자가 제공한 최신 `dasan-mes-app-main.zip`을 바탕으로 만든 수정 후보입니다. GitHub와 실제 Firebase에는 이 작업 중 변경을 가하지 않았습니다. 새 프로그램은 별도 설정이 없으면 **가상 재고 모드**로 시작합니다. 새로고침하면 가상 재고가 초기화됩니다.

## 지금 할 일

1. 이 ZIP을 컴퓨터에서 압축 해제합니다.
2. GitHub의 최신 `main`을 기준으로 `mes-safety-test`라는 새 작업용 복사본을 만듭니다. 기존 `mes-readonly-export`를 합치지 않습니다.
3. 새 복사본의 저장소 맨 바깥에서 `Add file → Upload files`로 **압축 해제한 폴더 안의 내용**을 올립니다. `src`, `public`, `tests`, `tools`, `docs` 폴더와 바깥 파일들이 들어가는 구조입니다. `src` 폴더 안에 전체 파일을 넣거나, `dasan-mes-safety-rc1` 폴더 자체를 한 겹 더 만들면 안 됩니다.
4. 저장 메시지를 `Add MES safety RC1 demo`로 하여 **mes-safety-test에 저장**합니다. `main`은 선택하지 않습니다.
5. Vercel에서 이 복사본의 Preview가 준비되면 `Visit`을 누릅니다. 새 환경변수나 Firebase 키를 추가할 필요가 없습니다. 첫 화면의 `가상 재고로 시험 시작`을 누르면 됩니다.

정상적인 시험 화면에는 **“시험용 가상 재고입니다. Firebase / 구글 시트 / 실제 프린터로 전송하지 않습니다.”**라는 안내가 나옵니다. `MIX-DEMO-...`가 시험 로트입니다. 실제 공장 로트나 운영 모드가 보이면 입력하지 말고 해당 창을 닫으세요.

> 이 프로그램을 main에 그대로 올리면 기존 운영 주소도 기본 가상 모드로 바뀔 수 있습니다. 실제 데이터가 삭제되는 것은 아니지만 현장 업무를 할 수 없게 됩니다. 운영 적용은 뒤의 검증을 마친 후 별도 작업입니다.

## 바뀐 점

- **영구 삭제 대신 취소와 원본 보관**: 잘못 만든 로트를 공정에서 제외해도 기존 내용, 사유, 담당자를 남깁니다. 종료 원본은 재고 합계에는 넣지 않고 로트 추적에서 찾습니다.
- **두 관리자 수정 화면에 같은 검사 적용**: 대시보드와 로트 추적의 수정·취소 처리가 같은 검사를 거칩니다. 미완료 공정을 앞으로 건너뛰는 것은 막습니다.
- **장비 연결 보호**: 실제 가동 중에는 수량·공정을 함부로 변경하지 않습니다. 정지된 장비에서 공정을 되돌리는 경우에는 해당 로트의 연결만 함께 정리합니다. 어느 칸에서 줄일지 불명확한 수량은 자동으로 추측하지 않고 중단합니다.
- **오래된 화면 값 차단**: 화면을 연 뒤 로트가 바뀌거나 분할·취소·출고되었으면 저장을 멈춥니다. 완료 버튼을 두 번 누르는 경우도 검사합니다.
- **분할 원본과 수량 보존**: 2차 성형과 수축률 분할에서 원본·자식 관계, 정상·불량 수량을 함께 확인합니다.
- **검수·건조·출고 묶음 저장**: 재고와 연결 기록을 같은 저장 작업으로 처리합니다. 샘플 출고는 불량이 아닌 별도 출고 기록입니다.
- **라벨 요청 보호**: 같은 조건의 중복 요청, 수량·수축률·제조일 변경 후의 부정확한 포장 완료를 검사합니다. 실제 인쇄 완료를 자동으로 확인하는 프린터 프로그램까지 수정한 것은 아닙니다.
- **연결 상태 표시**: 불러오는 중이나 연결 실패를 곧바로 재고 0으로 표시하지 않습니다. 담당자가 입력하는 동안 외부에서 같은 칸을 바꾼 경우도 확인합니다.

## 가상 화면에서 우선 해볼 것

- `검수/가공`의 시험 로트 10개 중 불량 1개와 사유를 넣고 완료하여, 다음 공정에 9개만 이동하는지 확인합니다.
- 시험 로트를 관리자 모드에서 취소하고, 현재 공정에서는 없어지지만 로트 추적에 **종료 원본 / 재고 아님**으로 남는지 확인합니다.
- 전기로에 시험 로트를 배정한 후 가동하고, 가동 중인 로트를 수량 수정·취소하려 할 때 멈추는지 확인합니다.
- `포장`에서 가상 라벨 요청과 포장 완료를 시험합니다. 실제 프린터에는 보내지 않습니다. 일반 출고 후 현재 재고와 출고 이력의 수량이 맞는지 확인합니다.
- 화면을 새로고침하면 처음의 시험 자료로 돌아오는 것이 정상입니다. 가상 모드의 결과는 실제 공장 자료로 저장되지 않습니다.

시험 중 오류가 있으면 오류 문구와 작업 순서만 기록하면 됩니다. 매 단계 화면 캡처를 보낼 필요는 없습니다.
