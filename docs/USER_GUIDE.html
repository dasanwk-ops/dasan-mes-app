이 수정본은 기본적으로 가상 재고만 사용합니다. 실제 브라우저 빌드, Firebase 보안규칙, 실제 프린터 검증은 아직 남아 있습니다.

이번에 준비한 것

사용자가 올린 최신 main을 기준으로 공정 저장과 관리자 수정 경로를 정리했습니다. 기존 화면과 업무 순서는 유지하고, 잘못된 저장은 중단하며 취소·분할·출고 원본은 따로 남기도록 바꿨습니다. 이미 보정한 실제 재고를 다시 변경하는 기능은 넣지 않았습니다.

영역변경 내용
관리자 수정·취소사유와 담당자를 남기고 최신 상태를 확인합니다. 영구 삭제 대신 원본을 보관합니다. 가동 중인 장비는 함부로 바꾸지 않습니다.
전기로·수축률다른 로트나 장비 값을 덮어쓰지 않도록 검사하고, 분할 수량과 부모·자식 관계를 확인합니다.
검수·건조·출고수량과 연결된 기록을 같이 저장합니다. 샘플 출고는 불량과 구분합니다.
라벨중복 요청과 조건이 바뀐 뒤의 포장 완료를 검사합니다. 원기록이 없는 667은 계속 보류합니다.
연결 상태불러오는 중과 연결 실패를 재고 0으로 오인하지 않도록 표시를 구분합니다.

실제로 확인한 범위

가상 데이터 자동 검사 62개 통과
중복 완료, 오래된 화면 저장, 분할 수량, 부분 저장 실패, 출고 잔량, 라벨 조건, 전체 공정 순서를 검사했습니다.

15개 화면 함수 구성과 대시보드 이동 참조, 소스 문법도 검사했습니다. 다만 화면 함수 검사는 실제 React나 브라우저가 아닌 간이 대역 검사입니다.

아직 하지 못한 것: 실제 React 빌드, Firebase Emulator, 현장 태블릿, 운영 보안규칙, 실제 프린터·Google Sheets 연동 검사입니다. 외부 설치 서버 연결 실패로 필요한 도구를 설치하지 못했습니다. 자세한 결과와 남은 위험은 묶음 안의 docs/REVIEW.md에 있습니다.

화면에서 확인할 표시

상단에 “시험용 가상 재고입니다. Firebase / 구글 시트 / 실제 프린터로 전송하지 않습니다.”라는 안내가 나와야 합니다. 시험 로트는 MIX-DEMO-...입니다.

실제 공장 로트나 운영 모드가 보이면 입력을 중단하고 창을 닫으세요. 가상 모드는 새로고침하면 처음의 시험 재고로 되돌아가는 것이 정상입니다.

간단한 시험

검수의 시험 로트 10개 중 불량 1개를 입력해 다음 공정에 9개가 넘어가는지, 관리자 취소 후 원본이 로트 추적에 남는지, 전기로 가동 중 강제 수정이 차단되는지 확인합니다. 가상 포장과 출고도 시험할 수 있지만 실제 프린터로 전송하지 않습니다.

단순 단계마다 캡처할 필요는 없습니다. 문제가 있으면 오류 문구와 직전에 한 작업을 기록해주세요.
