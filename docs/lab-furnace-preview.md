# 실험로 테스트 버전

테스트 브랜치: `lab-furnace-preview`. 운영 `main`은 변경하지 않았습니다.

## 확인 방법

1. PR #2의 Vercel **Preview** 링크를 엽니다. Vercel 계정 로그인이 필요할 수 있습니다.
2. 열처리 대기열의 `TEST-LAB-001` 샘플 6개를 선택합니다.
3. 작은 실험로 카드의 **단일 공간**을 눌러 수량을 배정합니다.
4. 담당 작업자를 입력하고 **실험로 가동 시작**을 누릅니다.
5. **실험로 완료 · 측정 이관** 후 수축률 측정 화면으로 이동합니다.
6. 실험로 한 칸에서 위치와 소결 전 면적(예: 100)을 입력하고 잠급니다.
7. 소결 후 면적(예: 90.25)을 입력해 수축률 5.00%를 확인하고 결과를 확정합니다.
8. 필요하면 상단 **샘플 초기화**로 다시 시작합니다.

샘플 데이터는 브라우저 탭 안에만 저장됩니다. 운영 Firebase SDK를 불러오지 않으며,
구글시트 전송과 실제 라벨 출력은 연결하지 않습니다. CSP의 `connect-src 'none'`으로
네트워크 데이터 전송도 차단합니다. 다른 탭·기기와 테스트 결과가 공유되지 않습니다.

## 검증 범위

- `node --test tools/test-heat-completion.cjs`: 18개 통과.
- `node --test tools/test-lab-sandbox.cjs`: 3개 통과.
- `CI=true npm test -- --watch=false --runInBand`: React DOM 흐름 테스트 1개 통과.
- `npm run build`: 기존 빌드 변환 스크립트를 포함해 성공.
- DOM 테스트에서 배정 → 시작 → 완료 → 면적 입력/잠금 → 수축률 확정 → 검수 이관을 검증.
- 다른 샘플 로트와 기존 전기로의 데이터 보존, 네트워크 전송 없음 확인.
- 실제 Firebase 연동과 태블릿 화면의 시각적 확인은 아직 하지 않았습니다.
