# 실험로 테스트 버전

테스트 브랜치: `lab-furnace-preview`. 운영 `main`과 운영 데이터는 변경하지 않습니다.

미리보기: https://dasan-mes-app-git-lab-furnace-preview-dasanwk-ops-projects.vercel.app
Vercel 계정 로그인이 필요할 수 있습니다. 기존 탭에서 새 샘플 분말 재고가 보이지 않으면 **샘플 초기화**를 누릅니다.

## 이번 변경

- 실험로는 층 구분 없는 단일 공간이며 여러 제품/로트를 함께 배정할 수 있습니다. 로트별 수량과 이력을 보존하고, 배정·가동·완료 때 합계 최대 10개를 검사합니다. 기존 배정을 제거하거나 잔여 용량에 다른 제품을 추가할 수 있습니다.
- 혼합에서는 실제 필요한 통의 배합량만 표시합니다. 미달 통만 필요하면 15kg 통 계산과 0통 표시는 나오지 않습니다.
- 실험용 발주에는 **실험용 생산**, **수축률 시편 포함** 선택이 있습니다.
- 시편을 제외하면 제품 단중 × 수량만 배합합니다. 일반 생산의 1% 및 200g 가산을 적용하지 않습니다.
- 시편을 포함하면 **일반 생산과 동일한 `제품 분말 × 1.01 + 0.200kg`**을 적용합니다. 별도의 시편 분말 입력란은 없습니다. 초기 테스트 버전에서 빠졌던 1% 가산을 복구하고 수동 시편 분말 설정을 제거했습니다.
- 실험용 주문 총수량은 10개보다 많아도 되며, 1회 공정 투입을 10개 이하로 나눕니다. 주문 BOM은 일반 생산과 같은 투입 1회 기준입니다. 실제로 나누어 투입할 때는 각 수량으로 다시 계산하며, 시편 포함 투입마다 1% + 200g 가산이 적용됩니다.
- 발주 옵션이 WIP, 배합, 성형, 열처리와 후속 공정에 보존됩니다. 실험용 부분 배합 생산 가능 수량에도 시편 포함 여부에 따른 1% + 200g 가산을 반영합니다.
- 실험로는 시편 위치 선택 없이 면적만 입력합니다. 로트별 **수축률 미측정** 선택으로 같은 회차에 측정품과 미측정품을 함께 처리할 수 있습니다. 일반 1·2호기 위치 검증은 유지합니다.
- 실험로에서는 면적 입력·잠금 전이나 후 모두 **수축률 미측정으로 검수 이관**을 사용할 수 있습니다. 시편 포함 주문도 실제 측정을 생략할 수 있습니다.
- 미측정은 수축률 `null` 및 `not_measured` 상태로 기록합니다. 원래 로트 ID·수량·기존 이력을 보존하고, 측정 이력 및 작업 아카이브를 추가합니다. 일부 입력한 면적도 아카이브에 남습니다.
- 미측정 이관은 현재 작업만 완료하며 다음 대기 작업을 유지합니다. 수량 불일치·다른 측정대의 중복 WIP·동시 변경은 이관을 막습니다.
- 포장 라벨은 불량을 제외한 정상 제품 1개당 1장으로 요청합니다. 버튼에 장수를 표시하고, 요청 후 해당 장수의 미리보기를 제공합니다. 출력 요청과 로트 출력 이력을 하나의 트랜잭션으로 저장하며 중복 클릭을 막습니다. 출력 후 수량/불량/LOT/수축률/실험용 상태가 달라지면 재출력해야 포장을 완료할 수 있습니다.
- 미측정으로 확정된 실험용도 포장할 수 있습니다. 수축률과 확대율을 `미측정`으로 전달하며, 기존 제품 코드·GTIN은 유지합니다. 실험용 구분 필드와 TEST 표시를 추가했습니다. 실제 인쇄 템플릿 및 프린터 출력은 아직 검증하지 않았습니다.
- 로트 추적에 **실험용 / TEST**, 시편 포함 여부, 미측정 여부를 표시합니다. `실험용`, `테스트`, `TEST`로 검색할 수 있고 출고 기록에도 실험용 정보를 보존합니다.
- 일반 1·2호기의 필수 측정과 일반 생산 분말 계산은 유지합니다.

## 확인 방법

### 발주부터 실험로까지

1. **발주 관리**에서 `345 BL0`, 단중 `628g`, 수량 `10개`를 입력합니다.
2. **실험용 생산** 선택 후 시편을 제외하면 예상 분말은 `6.280kg`입니다.
3. 다른 주문에서 시편을 포함하면 일반 생산과 동일하게 `6.543kg`으로 표시됩니다(계산값 6.5428kg, 계량 표시 1g 단위). 별도 분말 입력은 필요 없습니다.
   첨부 화면 재현: `234 BL2`, 단중 `650g`, 수량 `4개`에서 일반 생산과 실험용 시편 포함은 모두 합계 `2.826kg`, 원료별 `4Y-W-S 2.703kg / 4Y-Y 0.110kg / 5E-P 0.013kg`입니다. 실험용 시편 미포함 합계는 `2.600kg`입니다.
4. **공정 투입**으로 10개를 보내고 **원재료 창고 → 배합실 이관**을 누릅니다.
5. **혼합**에서 샘플 원재료 LOT와 작업자를 지정하고 배합을 완료합니다. 재고 차감 및 지시 중량을 확인합니다.
6. **1차 성형**에서 발주에 따른 시편 체크 상태를 확인합니다. **2차 성형**에서 수량을 배정하여 열처리로 보냅니다.
7. 열처리 대기 로트를 선택하고 작은 **실험로 → 단일 공간**에 배정합니다. 다른 대기 로트를 선택한 뒤 **선택 제품 추가**를 눌러 같은 공간에 추가합니다. 합계 10개까지 허용되며 각 로트는 따로 표시됩니다.
8. 작업자를 입력하고 가동 시작 → 완료·측정 이관합니다.
9. **수축률 측정 → 실험로 → 수축률 미측정으로 검수 이관**을 누릅니다. 면적 입력 없이 검수로 넘어가며 ‘미측정’ 이력이 표시됩니다.

### 바로 열처리/측정을 확인할 때

`TEST-LAB-001` 6개를 실험로에 넣어 테스트합니다. 측정하려면 위치 선택 없이 소결 전 면적 `100`, 소결 후 면적 `90.25`를 입력하면 `5.00%`로 확정됩니다. 입력을 생략하려면 미측정 이관 버튼을 사용합니다.

### 다품종·포장·추적 확인

1. 서로 다른 제품/로트 2개·3개·5개를 실험로에 추가합니다. 합계 10개 표시와 각 로트의 수량을 확인합니다. 잔여 용량보다 큰 로트를 추가하면 차단됩니다.
2. 가동 → 완료 후 측정대에서도 각 로트가 유지되고 위치 선택은 나오지 않습니다. 한 로트만 **수축률 미측정**으로 선택하고 다른 로트에는 소결 전/후 면적을 입력해 함께 확정합니다.
3. 검수·건조 후 포장에서 수량 3개에 불량 1개를 입력하면 **라벨출력 2장**으로 표시됩니다. 출력 후 미리보기는 2장, 각 라벨의 포장수량은 1개입니다. 미측정 실험품은 수축률/확대율이 `미측정`입니다.
4. 출력 후 불량수량을 바꾸면 재출력해야 포장완료가 됩니다. 같은 요청을 빠르게 두 번 눌러도 출력 작업은 한 건만 생성합니다.
5. 포장 및 출고 후 로트 추적에서 `실험용`으로 검색해 TEST 표시·시편 여부·이력이 보존되는지 확인합니다.

## 테스트 격리 및 검증

샘플은 브라우저 탭의 sessionStorage에만 저장됩니다. 운영 Firebase SDK를 불러오지 않으며, 구글시트 전송과 실제 라벨 출력은 연결하지 않습니다. CSP `connect-src 'none'`으로 네트워크 전송도 차단합니다. 테스트 결과는 다른 탭·기기와 공유되지 않습니다.

- `node --test tools/test-heat-completion.cjs tools/test-lab-sandbox.cjs`: 29개 통과.
- `CI=true npm test -- --watch=false --runInBand`: React DOM 통합 테스트 23개 통과.
- 기존 빌드 변환 스크립트를 모두 적용한 소스에서도 위 React DOM 테스트 23개 통과.
- `npm run build`: 성공.
- 실제 화면 핸들러로 시편 포함/미포함 발주 → 원재료 이관 → 실제 분말 차감 → 1·2차 성형 → 실험로 → 미측정 검수 이관 확인.
- 사용자 첨부의 650g × 4개 조건에서 일반/실험용 시편 포함의 원료별 BOM 및 창고 이관량 일치 확인.
- 일반 생산 계산, 정상 측정, 원료 부족 부분 배합, 10개 경계, 수량/중복/동시 변경 차단, 타 로트·전기로·대기 측정 보존, 네트워크 요청 없음 확인.
- 2+3+5 다품종 가동·이력 유지, 합계 용량 초과/중복 로트 차단, 로트별 측정/미측정 혼합, 미달/정량/혼합 통 표시, 포장 출력 장수·중복 클릭·동시 수량 변경·재출력 검증, 출고 후 TEST 검색을 추가 확인했습니다.
- 운영 Firebase 연동, 실제 프린터/인쇄 템플릿 및 태블릿에서의 시각적 확인은 아직 하지 않았습니다.

## 추후 운영 이식

**이 브랜치 전체를 main에 병합하면 안 됩니다.** 샘플 데이터 전용 코드가 포함되어 있습니다.

기능 변경만 담긴 커밋을 순서대로 적용합니다.

1. `ff7f062fedf972b4330a4bd507a0ada296dfee93`: 단일 공간 실험로.
2. `696913efc63d82de0197e28fc4136e1c0f9bd089`: 10개 제한, 실험용/시편 분말, 미측정 이관 및 빌드 변환 호환.
3. `f9e2c1443a41eca3ca997a6dfd68d6594110bdf7`: 시편 포함 실험용을 일반 생산과 동일한 계산으로 정정하고 수동 분말 입력 제거.

4. `74af770084a309abbce33607defd7fa79b652021`: 다품종 합계 10개, 실제 통 배합량만 표시, 실험로 위치 입력 생략/로트별 미측정, 라벨 장수 및 실험용 추적.

샘플 어댑터, 테스트 문서, 미리보기 네트워크 차단 설정을 담은 나머지 커밋은 이식 대상이 아닙니다. 사용자 테스트 후 당시 최신 main에 기능 변경만 적용하고 다시 검증합니다.

실험로 ID는 `lab`입니다. 기존 첫 배정 ID `SINGLE`을 유지하고, 추가 로트는 `LAB_<WIP ID>`로 저장합니다. 표시상 모두 같은 단일 공간이며 층이나 물리적 위치를 뜻하지 않습니다. 기존 1·2호기 및 예약 3·4호기 ID를 재사용하지 않습니다. 기존 데이터의 일괄 변경/삭제나 DB 마이그레이션은 포함하지 않습니다.
